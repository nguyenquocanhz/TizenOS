Tải về TizenOS 1.0

Chọn định dạng cài đặt phù hợp cho máy tính x86_64 hoặc ARM64 của bạn.

TizenOS Live ISO (Hybrid)

Phiên bản: 1.0.0-amd64 | Kích thước: 2.8 GB

Đĩa cài đặt Hybrid hỗ trợ boot trực tiếp trên cả UEFI (Secure Boot) và Legacy MBR BIOS. Tích hợp sẵn bộ cài đặt GTK4 tizenos-installer.

Tải ISO Trực tiếp (Direct ISO) 💿
# Kiểm tra SHA-256 Checksum:
sha256sum tizenos-live.iso

TizenOS Raw Disk Image (.img)

Phiên bản: 1.0.0-amd64/arm64 | Kích thước: 3.2 GB

Ảnh đĩa thô đã phân vùng sẵn thích hợp để flash ra USB/SD Card qua balenaEtcher hoặc chạy thử nghiệm ảo hóa QEMU/KVM.

Tải Tệp .img 💾
# Flash ra USB:
sudo dd if=tizenos-disk.img of=/dev/sdX status=progress

🖥️ Khởi chạy Thử nghiệm Ngay trên QEMU / KVM

Bạn có thể test trực tiếp đĩa TizenOS Live ISO ngay trên máy tính mà không cần cài đặt bằng lệnh QEMU sau:

qemu-system-x86_64 -cdrom tizenos-live.iso -m 4G -enable-kvm -vga virtio -display default
